# rain toe

Started with Ardux and heavily modified to make a new, different layout - "rain toe". \
This is intended to just be an 8 key layout; not extended. \
It's primarily left-handed. Might make a right-handed version later. \
I like the concept of Big Ardux etc, but I don't need them and want to concentrate on getting "rain toe" working first. \
Layout editable in the amazing https://nickcoutsos.github.io/keymap-editor/ \
